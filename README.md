# Team Task Board

A simple task board created by our team using HTML, CSS, and JavaScript.

## Project Description

This project is a small task management board where users can view tasks and manage their status.

## Team

- Member 1 – Project Setup
- Member 2 – Task Board UI
- Member 3 – Task Functionality

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Display tasks
- Manage task status
- Simple and readable user interface
## Project Structure

- `index.html` - Main structure of the task board
- `style.css` - Styling and layout of the task board
- `script.js` - Task management functionality
- `README.md` - Project documentation
- `.gitignore` - Specifies files ignored by Git

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
